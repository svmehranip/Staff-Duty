# StaffDuty GitHub Complete Replacement

Replace the existing GitHub Pages web files with:
- index.html
- app.js
- style.css
- manifest.json
- sw.js

IMPORTANT: In app.js, keep your existing Google Apps Script Web App URL by replacing:
PASTE_YOUR_EXISTING_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE

This version includes:
- One-owner approval
- Multi-day leave with Start/End date
- Full day / Half Day Morning / Half Day Evening
- Staff-wise monthly leave summary for Owner
- Owner removal of Pending and Approved leaves
- Change password
- Visible Logout
- Button click animation
- Android 3-button / gesture safe-area support
